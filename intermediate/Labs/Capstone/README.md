# Module 7 — Capstone: Nutanix AIOps Pipeline

A production-grade anomaly detection and LLM remediation system for Nutanix CVM telemetry.

---

## What This Project Does

```
CVM Telemetry Metrics
        │
        ▼
Feature Engineering (rolling stats, z-scores, derived ratios)
        │
        ▼
Isolation Forest Anomaly Detection
        │
        ▼
Gemini LLM → Root Cause + Remediation Steps
        │
        ▼
JSONL Audit Log  ←→  FastAPI REST API  ←→  Streamlit Dashboard
```

## How to Run

### Option A — Streamlit App (recommended for workshop)

Self-contained — trains its own model, no external dependencies.

```bash
cd "AI:ML intermediate"
"/Users/name/AI:ML intermediate/myenv/bin/python3" -m streamlit run Module_7/nutanix_aiops_app.py
```

Open: **http://localhost:8501**

**App tabs:**
- **Overview** — architecture and model performance
- **Live Detection** — paste CVM metrics → get anomaly score + remediation
- **Batch Pipeline** — process multiple nodes at once
- **Audit Log** — searchable history of all detections
- **Dashboard** — charts: anomaly rate, severity distribution, LLM cost

### Option B — FastAPI Server (production microservice)

Requires `nutanix_anomaly_model.joblib` to exist (run notebook Section 3 first).

```bash
cd "AI:ML intermediate/Module_7"
"/Users/name/AI:ML intermediate/myenv/bin/python3" -m uvicorn nutanix_aiops_api:app --reload --port 8080
```

Open: **http://localhost:8080/docs**

**Endpoints:**

| Method | Endpoint | Description |
|--------|---------|-------------|
| `GET` | `/health` | Server health check |
| `GET` | `/model/info` | Model metadata (features, contamination, offset) |
| `POST` | `/detect` | Run anomaly detection on CVM metrics |

**Example POST /detect request:**

```bash
curl -X POST "http://localhost:8080/detect" \
  -H "Content-Type: application/json" \
  -d '{
    "node": "node-1",
    "cpu_pct": 94.0,
    "mem_pct": 91.0,
    "disk_read_mbps": 118.0,
    "disk_write_mbps": 79.0,
    "network_mbps": 495.0,
    "iops": 19500.0,
    "latency_ms": 42.0,
    "stargate_ops_per_sec": 350.0
  }'
```

**Example response:**

```json
{
  "node": "node-1",
  "is_anomaly": true,
  "anomaly_score": -0.672,
  "confidence": 1.0,
  "severity": "critical",
  "timestamp": "2026-05-30T10:13:09Z",
  "feature_contributions": {
    "latency_ms": 76.42,
    "latency_iops_ratio": 18.66,
    "cpu_mem_pressure": 10.92
  }
}
```

## Troubleshooting

### `zsh: command not found: streamlit`
Streamlit is installed in the venv but not on the system PATH.
```bash
"/Users/name/AI:ML intermediate/myenv/bin/python3" -m streamlit run Module_7/nutanix_aiops_app.py
```

### `zsh: command not found: uvicorn`
Same issue — use full path:
```bash
"/Users/name/AI:ML intermediate/myenv/bin/python3" -m uvicorn nutanix_aiops_api:app --port 8080
```

### `No module named uvicorn` or `No module named streamlit`
Install missing packages:
```bash
"/Users/name/AI:ML intermediate/myenv/bin/pip3" install uvicorn streamlit fastapi
```

### `Could not import module "nutanix_aiops_api"`
You are running uvicorn from the wrong directory. You must `cd` into `Module_7` first:
```bash
cd "AI:ML intermediate/Module_7"
"/Users/name/AI:ML intermediate/myenv/bin/python3" -m uvicorn nutanix_aiops_api:app --port 8080
```

### `RuntimeError: Model not found at nutanix_anomaly_model.joblib`
The saved model file does not exist. Run the notebook first:
- Open `Lab_7_Capstone_AIOps_Pipeline.ipynb`
- Run cells up through **Section 3 — Anomaly Detection Model**
- This saves `nutanix_anomaly_model.joblib`

### `[Errno 48] Address already in use`
Port is occupied by a previous run. Use a different port or kill the process:
```bash
# Option 1 — use a different port
python3 -m uvicorn nutanix_aiops_api:app --port 8090

# Option 2 — kill the process on 8080
lsof -ti:8080 | xargs kill -9
```

### `GEMINI_API_KEY not set` or `InvalidArgument: API key not valid`
- Check that `.env` exists in `AI:ML intermediate/` with `GEMINI_API_KEY=AIza...`
- Or paste the key directly in the Streamlit sidebar
- Regenerate at: https://aistudio.google.com/app/apikey

### `404 models/gemini-1.5-flash is not found`
Model deprecated. The app uses `gemini-3.1-flash-lite` — verify the sidebar dropdown shows this model.

### `429 ResourceExhausted — Quota exceeded`
Free-tier limit hit. Wait 60 seconds and retry. The free tier resets per minute.

### Streamlit performance warning: `install watchdog`
Not an error — just a performance hint. The app runs fine without it.
```bash
# Optional — only install if you want faster hot-reload
xcode-select --install
pip install watchdog
```

## Model Details

- **Algorithm:** Isolation Forest
- **Training data:** 1000 synthetic normal CVM samples + injected anomalies
- **Features:** 20 (8 raw telemetry + 8 rolling stats + 4 derived ratios)
- **Contamination:** 5% (expected anomaly rate)
- **Severity thresholds:** confidence > 0.85 → critical, > 0.60 → warning

**Key features:**

| Feature | Description |
|---------|-------------|
| `cpu_pct` | CVM CPU utilisation % |
| `mem_pct` | CVM memory utilisation % |
| `iops` | Storage IOPS |
| `latency_ms` | Storage latency (ms) |
| `disk_read/write_mbps` | Disk throughput |
| `stargate_ops_per_sec` | Stargate storage operations/sec |
| `cpu_mem_pressure` | `cpu_pct × mem_pct / 100` |
| `latency_iops_ratio` | `latency_ms / (iops/1000)` |
